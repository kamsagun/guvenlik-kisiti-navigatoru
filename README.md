# Güvenlik Kısıtı Navigatörü · Seri 05

Bu paket GitHub Pages üzerinde aşağıdaki proje adresi için hazırlanmıştır:

`https://kamsagun.github.io/guvenlik-kisiti-navigatoru/`

## Yayımlama

1. GitHub'da `guvenlik-kisiti-navigatoru` adlı yeni bir depo oluşturun.
2. Bu klasörün içindeki bütün dosya ve klasörleri deponun kök dizinine yükleyin. ZIP dosyasını tek başına yüklemeyin.
3. Deponun **Settings → Pages** bölümünü açın.
4. **Build and deployment** altında kaynak olarak **Deploy from a branch** seçin.
5. Dal olarak **main**, klasör olarak **/(root)** seçip kaydedin.
6. GitHub yayımlamayı tamamladığında siteyi yukarıdaki adresten açın.

## Sayfalar

- Ana sayfa: `/guvenlik-kisiti-navigatoru/`
- Değerlendirme aracı: `/guvenlik-kisiti-navigatoru/arac/`
- Açıklama ve öğrenme rehberi: `/guvenlik-kisiti-navigatoru/rehber/`

## Önemli notlar

- Paket `guvenlik-kisiti-navigatoru` depo adına göre yapılandırılmıştır. Depo adı değiştirilirse sayfa ve varlık yolları da değiştirilmelidir.
- Değerlendirme kayıtları sunucuya gönderilmez; ziyaretçinin kendi tarayıcısındaki yerel depolamada tutulur.
- Depo herkese açıksa kaynak kodu, görseller ve bilimsel dayanak PDF'si de herkese açık olur.
- `.nojekyll` dosyasını silmeyin.
